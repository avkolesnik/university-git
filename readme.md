#  Десктоп-приложение для учета личных финансов с графическим интерфейсом на Python. 
## Позволяет контролировать доходы и расходы, анализировать финансовые привычки и планировать бюджет.

# Возможности

## Учет операций
### Добавление/удаление/редактирование финансовых операций
### Категоризация доходов и расходов
### Автоматическое присвоение ID
### Поиск и фильтрация по категории, дате, типу операции
### Валидация ввода с использованием регулярных выражений

## Анализ и отчеты
### Расчет текущего баланса в реальном времени
### Анализ расходов по категориям
### Сравнение доходов и расходов за период

## Визуализация
### Графики динамики расходов (линейные графики)
### Круговые диаграммы распределения по категориям
### Столбчатые диаграммы для сравнения

## Работа с данными
### Хранение в CSV/JSON форматах
### Экспорт данных в различные форматы:
### - Для Excel (UTF-8-BOM, разделитель ";")
### - Универсальный CSV (UTF-8)
### - JSON для интеграции

## Надежность
### Обработка ошибок на всех уровнях
### Валидация данных при вводе
### Предотвращение потери данных
### Логирование ошибок в файл
### Unit-тесты для ключевых функций

# Основные функции
## 1. Добавление операции
### 1.1. Заполните форму в левой панели:
### - 1.1.1. Выберите тип (доход/расход)
### - 1.1.2. Введите сумму
### - 1.1.3. Укажите категорию
### - 1.1.4. Выберите дату (или оставьте текущую)
### - 1.1.5. Добавьте описание (опционально)
### 1.2. Нажмите "Добавить операцию"

## 2. Просмотр истории
### Все операции отображаются в таблице
### Сортировка по дате (новые сверху)
### Показываются последние 100 операций

## 3. Управление операциями
### Удаление: Выберите операцию → "Удалить выбранное"


## 4. Анализ данных
### - Баланс: Показывает текущее состояние счетов
### - Расходы по категориям: Анализ за последние 30 дней
### - Графики: Визуализация данных в различных форматах
### - Отчеты: Детализированные финансовые отчеты

## 5. Экспорт
### - Для Excel (рекомендуется для Windows)
### - Универсальный CSV
### - JSON для программистов
